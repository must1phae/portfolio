# Mustapha — Personal 3D Portfolio

This is a small Vite + React portfolio scaffold built with Tailwind CSS, Framer Motion, and @react-three/fiber (Three.js).

Features
- Futuristic dark theme with neon highlights
- 3D floating cubes (Three.js)
- Smooth Framer Motion transitions
- Responsive layout

Quick start (Windows PowerShell)

1. Install dependencies

```powershell
npm install
```

2. Run dev server

```powershell
npm run dev
```

Open http://localhost:3000 in your browser.

Notes
- The contact form is a placeholder; wire it to your preferred backend or form service.
- Optionally replace the Three.js canvas with a Spline scene by embedding the Spline iframe or using the Spline SDK.
